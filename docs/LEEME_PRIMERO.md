# Antes de probar esta versión

1. Copia esta carpeta sobre tu proyecto de Fleet Command.
2. En la raíz ejecuta `npm install` y después `npm start`.
3. Si ya tienes `gcw.score` con solo `id`, `nombre` y `score`, ejecuta UNA VEZ `database/gcw_actualizacion_segundo_avance.sql` en Workbench.
4. Copia `backend-xampp/WebServices` a `C:\xampp\htdocs\WebServices`.
5. Inicia Apache y tu servidor MySQL.
6. Abre `http://localhost/WebServices/health.php`.
7. Abre Fleet Command desde `http://localhost:3000`.

Para entender cada cambio y cada función nueva, lee `DOCUMENTACION_AVANCE_2.md`.

Para Meta/Facebook, sigue `CONFIGURACION_META.md`.

Para instalación detallada y soluciones alternativas, lee `INSTRUCCIONES_INSTALACION.md`.
