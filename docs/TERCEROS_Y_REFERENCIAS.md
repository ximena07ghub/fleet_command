# Terceros y referencias

## Three.js
La escena 3D, cargadores OBJ/MTL/FBX, iluminación, `Raycaster`, `Box3` y renderizado utilizan Three.js instalado mediante npm.

## Bootstrap
Se usa Bootstrap localmente para los modales y parte de la distribución del HUD de la partida.

## Socket.IO
Se utiliza para sincronizar la sala y el estado de barcos entre dos navegadores.

## Meta / Facebook
El inicio de sesión externo usa el SDK de JavaScript de Facebook y los permisos `public_profile` y `email`.

## Modelos 3D
Los archivos `yamato.fbx` y `enemigo_dificil.fbx` fueron proporcionados para este proyecto. Antes de una publicación pública o comercial, confirma la licencia y procedencia de ambos modelos y de cualquier textura asociada.

El submarino OBJ/MTL se conserva como referencia del ejercicio de carga de modelos visto en clase.
